Societas Magica — Site Work Action Map

How to use this deck

Each card shows a task that needs to be done. Read the preview on each card to understand the problem and why it matters. Click "Details" to see technology options, cost/effort estimates, and implementation approaches. Cards are prioritized by category: fix what's broken first, then quick improvements, then long-term projects.

Color coding: Essential = must do soon | Nice to Have = valuable when capacity allows

1. Fixing Existing Functionality

Fix broken pages and outdated content first — these undermine credibility and must be addressed before moving forward.

Restore Contact Page (404)
Essential Critical

The contact page returns HTTP 404. Visitors and journalists cannot reach the organization. This is a credibility killer.

Journalists, prospective members, and institutional partners all expect a working contact form. A broken page is a missed opportunity.

Stabilize PayPal/Payment Processing
Essential Critical

PayPal IPN broke recently. Members paid their dues but were never activated. This is the #1 failure point for a membership org.

When payment doesn't activate membership, you lose both the member AND the revenue. This must be diagnosed and fixed immediately.

Update Stale Content (Last changed 2012)
Essential

Multiple pages show "Updated: January 12, 2012" or are missing current information. This makes the site look dormant.

Membership benefits, publications, officer bios, and conference info all need updates. This is the most visible credibility issue.

Assess Member Directory State
Essential

The member directory is login-gated, but its current state is unknown. How many members? Does search work? Can members edit profiles?

The member list is the core value of the site. If it's broken, the whole membership program is undermined.

Verify Newsletter PDF Archive
Nice to Have

All 44 newsletter PDFs are hosted on the current server. If the site migrates, these files must be moved or re-linked.

A broken newsletter archive kills credibility. Scholars expect 30 years of organizational history to be accessible.

2. Short-Term Easy Improvements (1–2 weeks)

Low-effort wins that reduce webmaster burden and improve usability. These run in parallel with fixes.

Build Member Management Dashboard
Essential

Officers need to know: How many active members? Who is lapsed? When do memberships expire? Currently requires database queries or outdated spreadsheets.

A simple admin view solves this. Active members, lapsed members, expiring soon, new this month, plus CSV export for reports.

Officer Directory Self-Management Form
Essential

Updating the officer directory currently requires editing files. When someone becomes president, someone forgets to update the page. This caused the 404 contact page.

A form prevents breakage. Officers can update their own entries. The page renders from the database and is never stale.

Set Up Role-Based Admin Access
Nice to Have

Currently: you either have full server access or no access. The newsletter editor can't publish. The treasurer can't view payment records.

Define roles: Newsletter Editor, Blog Editor, Treasurer (read-only), Officer (edit own info). Each person can do exactly what they need.

Newsletter Upload & Publish Interface
Essential

Publishing a newsletter requires FTP access and manual page editing. The editor is blocked; the webmaster must do it.

A simple form: upload PDF, enter Season/Year/Issue#, click Publish. Everything else happens automatically.

Integrate Member Email List with Membership DB
Essential

The member email list is a separate system not synced with the website database. New members aren't added. Lapsed members stay on the list.

Merge them. Active members automatically get announcements. Lapsed members stop. One source of truth: the membership database.

3. Long-Term Labor-Intensive Improvements (2–6 months)

These transform the site from a maintenance burden into a field resource. They address declining attendance by making the Societas a destination scholars visit.

Create Living Bibliography of Magic Studies
Nice to Have Field Builder

Magic studies publications are scattered across a dozen disciplines. There's no single searchable source. Scholars constantly miss relevant work.

A searchable bibliography makes the Societas a destination. Non-members can access it — a recruitment tool. RSS feed for specialists.

Dissertation Registry & Grad Student Hub
Nice to Have Membership Growth

Graduate students are the future of conference attendance. The site has no hook into this community. Dissertations are invisible to each other.

A searchable registry connects grad students, mentors, and collaborators. Early recruitment of future members.

Field-Wide Conference Calendar & CFP Digest
Nice to Have Engagement Driver

Magic studies scholars present at 50+ conferences annually. There's no single place to see CFP deadlines. Scholars miss submissions.

A calendar scholars bookmark and check monthly. Members submit CFPs. Monthly digest of upcoming deadlines.

Rich Member Profiles with ORCID Integration
Nice to Have Collaboration Tool

Currently: member directory is a phone book. Potential: a discovery tool where members find peer reviewers, committee members, session organizers by specialty.

Enrich profiles with research interests, projects, recent pubs (auto-pulled from ORCID), availability for peer review/committees/media.

Ars Magica Blog — Editorial Program
Nice to Have Visibility + Community

One blog post from 2021. A dormant blog signals a dormant organization. With editorial commitment, 6–8 posts/year becomes shareable content.

Posts like: research previews, source spotlights, pedagogical pieces, conference reports, book forums, dissertation spotlights.

Open-Access Working Papers (via Zenodo)
Nice to Have Field Infrastructure

Scholars have conference papers and draft chapters that are substantial but not journal-ready. They sit on hard drives, uncited.

Papers hosted with Societas branding get cited. Those citations carry the organization's URL. Free DOI via CERN's Zenodo.

Virtual Event Infrastructure
Nice to Have

In-person attendance is down across academia. Travel costs, visa issues, accessibility. Virtual events extend reach to members who can't get to Kalamazoo.

Annual lecture, pre-Kalamazoo roundtable (remote scholars ask questions), quarterly working groups, grad mentorship cohorts.

Implementation Roadmap

Phase 1 (Weeks 1–4): Stabilize
Restore contact page, fix PayPal, update stale content, build member dashboard, create officer self-management form. Goal: Basic credibility and functionality.
Phase 2 (Weeks 5–12): Reduce Burden
Newsletter upload interface, email list integration, blog editorial program. Goal: Free up webmaster time, establish regular content flow.
Phase 3 (Months 4–6): Build Resources
Bibliography, dissertation registry, conference calendar, rich member profiles. Goal: Make the site a field resource, drive attendance and engagement.
Phase 4 (Ongoing): Amplify
Working papers, expert directory, virtual events. Goal: Long-term visibility and community building.
